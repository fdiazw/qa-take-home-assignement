# Demo-Blaze

# 1. Installation

1. To get started, first clone or download the repo
2. Install dependencies `npm install`
3. Open a terminal or command line
4. Create a .env file at root with the following credentials:

```bash
USERNAME = 'user134@email.com'
PASSWORD = 'admin1234.'
```

5. Run `npm run smoke-test` to run the smoke test cases

# 2. Running scenarios

1. Go to package.json and note there are some scripts you can run
2. Open a terminal or command line
3. Run `npm run test`

Additionaly you can run test by installing the official Playwright extension if you are using VSCode
